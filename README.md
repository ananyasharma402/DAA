# Design and Analysis of Algorithms (DAA)

## 📌 About the Repository

This repository contains Java implementations of various algorithms and problem-solving techniques studied as part of **Design and Analysis of Algorithms (DAA)**.

The goal of this repository is to practice data structures, understand algorithmic approaches, and analyze the time and space complexity of different algorithms.

## ▶️ How to Run the Programs

1. Install the Java Development Kit (JDK).
2. Clone this repository:

   ```bash
   git clone https://github.com/ananyasharma402/DAA.git
   ```

3. Navigate to the repository folder:

   ```bash
   cd DAA
   ```

4. Compile the Java file you want to execute. For example:

   ```bash
   javac BubbleSort.java
   ```

5. Run the compiled program:

   ```bash
   java BubbleSort
   ```

**Note:** Replace `BubbleSort` with the appropriate class name for the program you want to run.
